# 一次資料

このディレクトリには，原稿作成の直接の基準にする資料を置く。

- `text/`: 使用テキスト，講義ノート，授業資料など，章番号・定理番号の基準にする資料。
- `user_notes/`: 手書きノート，自作ノート，ゼミメモ，補足 PDF など，説明・行間・注意点を補う資料。
- `translation_style/`: 洋書や英語講義ノートを日本語の数学本文へ移すときに参照する文体・用語資料。

補助的な数学参考 PDF は原則として `../references/` 以下に置く。
権利上共有できない資料は，テンプレート配布物に含めない。

## 運用

- 主テキストの配置と役割は `PROJECT_PROFILE.md` に記録する。
- ユーザー作成ノートと主テキストの対応は `HANDWRITTEN_INDEX.md` に記録する。
- 文体・用語資料は数学的主張の根拠ではなく，日本語表現や訳語確認の補助資料として扱う。数学的主張の根拠として使う場合は，通常の参考文献と同じく `references/` に記録する。
- 古いノートや旧版資料がある場合は，現行作業で使うかどうかを `HANDWRITTEN_INDEX.md` に明示する。
