# 完成 PDF 末尾の参考文献方針

## 目的

完成版 PDF の末尾に置く参考文献一覧は，主テキストの参考文献一覧を機械的に再掲する場所ではない。
この PDF の本文，脚注，証明補足，注意，訳語確認で実際に使った文献だけを載せる。
主テキストに含まれる文献でも，この完成 PDF で実際に参照していないものは載せなくてよい。

本文中の脚注や注釈は「どこを使ったか」を示し，末尾の参考文献一覧は「どの文献を使ったか」を示す。

## 本文中の注釈と末尾一覧の役割

- 本文中の注釈には，文献名に加えて，必要な節番号，定理番号，命題番号，補題番号，ページ番号を書く。
- 末尾の参考文献一覧には，原則としてページ番号や定理番号を書かない。
- 末尾の参考文献一覧に書くのは，著者，年，書名または論文名，出版社・雑誌・講義名，URL などの書誌情報である。
- どの定理やページを使ったかは，本文脚注，作業メモ，または `references/notes/` に残す。

## 掲載基準

1. 本文，脚注，注意，証明，訳語確認で実際に参照した文献だけを載せる。
2. 台帳にあるだけの未使用 PDF は載せない。
3. 主テキストの参考文献でも，この完成 PDF で使っていなければ載せない。
4. ユーザー作成ノートの色指定に基づく書籍参照は，該当箇所で実際に使った巻や資料だけを載せる。
5. Math StackExchange，MathOverflow，Stacks Project，講義ノート，Web PDF は，本文や脚注で実際に根拠として使った場合だけ載せる。

## 新しく参考文献が増えた場合

1. 新規 PDF や URL を見つけた時点では，完成 PDF 末尾の参考文献一覧にはまだ入れない。
2. まず `references/pdfs/` に置くか，公開 URL だけを使うかを決め，`references/REFERENCE_INDEX.md` または `references/notes/reference_inventory_full.md` に，資料名，著者，取得元，主題タグ，想定使用箇所を記録する。
3. ユーザー作成ノート由来の略記，色付き矢印，URL なしメモから見つけた場合は，`references/notes/handwritten_reference_aliases.md` と照合し，判読根拠を残す。
4. 本文，脚注，注意，証明補足のどこで使うかを決め，必要なら節番号，定理番号，命題番号，補題番号，ページ番号を本文側の脚注または `references/notes/` に記録する。
5. 実際に本文へ反映した後で，`final/references.tex` に `\bibitem` を追加する。キーは安定した短い識別子にする。
6. Web 資料は URL と最終確認日を入れる。ローカル PDF しかない資料は，ローカルパスを完成 PDF には出さず，著者・題名・出版情報だけを書く。
7. 後の改訂で本文から使わなくなった文献は，台帳やメモには残してよいが，完成 PDF 末尾の参考文献一覧からは外す。

## 基本書式

### 書籍で省略しない情報

通常の書籍は，著者名と書名だけで済ませない。
確認できる範囲で，巻・副題，版，翻訳者，叢書名と巻番号，出版社，刊行地，刊行年，ISBN，原著情報を入れる。
未確認の情報は推測で補わないが，出版年・出版社・巻名が確認済みなのに省略してはならない。

### 和書

著者（年）．『書名』．出版社．

### 和文論文・報告集内論文

著者（年）．「論文名」．『誌名または報告集名』，巻号，ページ範囲．

### 欧文書籍

Author, A. (Year). *Title*. Publisher.

### 欧文論文

Author, A. (Year). Title. *Journal*, volume(issue), pages.

### 講義ノート・プレプリント・Web PDF

Author, A. (Year or n.d.). *Title* [Lecture notes / Preprint / PDF]. Institution or course, URL.

### Web ページ

著者または組織名（年または n.d.）．ページタイトル．URL（最終確認: YYYY-MM-DD）．

## 並べ方

- 原則として著者名順に並べる。
- 和文文献と欧文文献を分ける必要はないが，混在して読みにくい場合は「和文文献」「欧文文献」「Web 資料」程度に分けてよい。
- 主テキスト由来か，今回追加した補助文献かで分ける必要はない。分けるのは，読者にとって文献種別が分かりやすくなる場合だけにする。

## ローカル管理情報

- `references/pdfs/` のローカルパスは，完成 PDF の参考文献一覧には原則として出さない。
- ローカルパス，取得元，確認ページ，使用箇所は `references/notes/` に残す。
- 公開 URL が確認できる場合だけ，参考文献一覧に URL を入れる。
- 公開 URL が確認できないローカル PDF は，書誌情報だけを書く。書誌情報が不足する場合は，不足箇所を推測で埋めない。

## 雛形

```tex
\subsection*{参考文献}

\begin{thebibliography}{99}
\bibitem[Key]{Key}
Author, A. (Year). \textit{Title}. Publisher.

\bibitem[WebKey]{WebKey}
Organization (n.d.). \textit{Page title}. \url{https://example.com}（最終確認: YYYY-MM-DD）.
\end{thebibliography}
```
