## 優先度

| 優先度 | 意味 |
| --- | --- |
| 高 | 主テキストやユーザー作成ノートが直接参照している，または対象分野の標準文献。 |
| 中 | 補足証明，用語確認，背景確認に使う可能性がある。 |
| 低 | 関連はあるが，現時点では本文に使う見込みが薄い。 |

## 本文使用

| 状態 | 意味 |
| --- | --- |
| 未使用 | 台帳にあるだけで，本文では使っていない。 |
| 候補 | 対象箇所の根拠候補として確認中。 |
| 使用済み | 本文，脚注，証明補足，訳語確認で実際に使った。 |
| 不採用 | 確認した結果，本文では使わない。 |

## 運用

- 参考文献 PDF を追加したら，まずこの一覧か `REFERENCE_INDEX.md` に登録する。
- 本文で使ったら，使用箇所と用途を個別メモまたは `REFERENCE_INDEX.md` に記録する。
- Git 管理しない資料は「ローカル保管」と明記する。
- 大容量 PDF を分割した場合は，元ファイル，分割範囲，サイズを記録する。
